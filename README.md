# MTO Data Portfolio — Two End-to-End Projects

These projects are designed to demonstrate practical SQL and Power BI skills for Product Management and Strategic Projects applications.

**Important:** All company/product names, records, metrics and findings are fictional synthetic examples. They are not Programming Hero or Fibu data.

## Project 01 — SQL Product Analytics
- Business case: diagnose acquisition, activation, learning funnel, retention, subscription cancellations and support friction.
- Raw data: intentionally includes duplicates, inconsistent labels, missing values and formatting issues.
- Cleaned data: normalized and deduplicated tables for analysis.
- SQL: 8 business questions with SQLite-compatible queries.
- Results: query output CSVs and a SQLite database.

## Project 02 — Power BI Executive KPI Dashboard
- Business case: give a COO an integrated view of commercial growth, learning outcomes, service quality, project delivery and budget.
- Raw data: deliberately messy monthly performance and team operations files.
- Cleaned data: fact tables and dimensions prepared for a star-schema model.
- Power BI: import workbook, DAX measures, report build guide and an Excel KPI preview.
- Note: a native `.pbix` cannot be authored in this environment. The supplied workbook, cleaned CSVs, DAX and page-by-page build guide are ready to import into Power BI Desktop.

## Recommended portfolio presentation
1. Lead with the business problem and the decisions the analysis supports.
2. Show the data model and a small number of important queries/measures.
3. Show the key findings and caveats.
4. End with 2–3 prioritised recommendations and how you would measure impact.

Do not present synthetic results as real company performance. Before publishing, personalise the recommendations and be ready to explain every query, transformation and measure.
